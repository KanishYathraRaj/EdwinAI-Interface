# **App Name**: Edwin

## Core Features:

- Interactive Chat Interface: A text input area for composing prompts and a scrollable display area to show the ongoing conversation.
- AI-Powered Chatbot: An AI chatbot leveraging a language model tool to understand prompts, generate contextually relevant responses, and carry on multi-turn conversations.
- New Chat Sessions: Allows users to initiate fresh conversations, clearing the current context and preparing for new topics.
- Conversation History: A sidebar that saves and displays titles or summaries of past chat sessions, enabling users to revisit previous topics.
- Context Management: The chatbot maintains conversation history and context, providing more coherent and relevant responses throughout the chat.

## Style Guidelines:

- Use a Perplexity-like color scheme with a clean, modern feel, likely involving gradients and subtle contrasts.
- Adopt a ChatGPT-like interface layout, featuring a prominent text input area and a clear, scrollable chat display.
- Font: 'Inter', a grotesque-style sans-serif font that looks modern and objective; use it for both headings and body text.
- Subtle animations and transitions to provide feedback to user actions, like sending messages or starting new chats.
